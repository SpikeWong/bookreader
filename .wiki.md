# Project Summary

The English Book Reader project is a web-based application aimed at providing users with an engaging platform to enhance their English reading and learning experience through various books. The primary business objective is to facilitate improved language comprehension by integrating features such as real-time translation, text-to-speech capabilities, and personal book management functionalities. This platform serves casual readers as well as language learners, with tools that support reading comprehension and vocabulary enhancement. Through a user-friendly interface and features like the integrated Google Translate API for multilingual support, the application strives to create a comprehensive and immersive reading environment.

## Project Module Description

### 1. User Authentication
- **Login and Registration**: Users can create personal accounts and log in securely using either email/password or OAuth options (Google and GitHub).
- **User Profile Management**: Users can update their profile information, including display name and preferred language.

### 2. Book Management
- **Book Upload**: Admins can upload various formats of books (EPUB, PDF, TXT) via a dedicated interface.
- **Book Listing**: Users can view a categorized list of available books with search and filter capabilities.
- **Bookshelf Functionality**: Users can manage their personal bookshelf, adding or removing books as needed.

### 3. Reading Features
- **Book Reader**: Users can read books with features such as word and sentence translations triggered by user actions.
- **Text-to-Speech Integration**: The application offers audio pronunciation for words and phrases to enhance learning.
- **Reading Progress Tracking**: Users can track their reading progress through each book, which is saved across user sessions.

### 4. Personal Bookshelf
- Users can save books to their personal bookshelves, organize them, mark favorites, and track their reading progress.

### 5. Responsive Design
- The application is designed to be fully functional on various devices, providing a seamless reading experience across desktops, tablets, and mobile devices.

### 6. API Key Management
- Users can manage their Google Translate API key through an integrated UI component, allowing for customizable translation settings.

## File Description Inventory

- **Backend Files:**
  - `src/index.js`: Main server file that initializes the Express application and configures middleware.
  - `src/routes/*`: Define the various API routes for authentication and book management.
  - `src/controllers/*`: Contain the business logic for handling requests and responses.
  - `src/models/*`: Define data models for users and books.
  - `src/utils/fileParser.js`: Utility functions for parsing book files.

- **Frontend Files:**
  - `src/App.jsx`: Main application component that contains routing and layout.
  - `src/components/*`: Contains components for managing books, user profiles, authentication, and other features.
  - `src/utils/api.js`: Defines functions for interacting with the backend API for authentication and data management.
  - `src/config/apiConfig.js`: Handles the configuration and management of the Google Translate API key.

## Technology Stack

- **Backend**: Node.js, Express, MongoDB (or appropriate storage mechanism), JWT, bcrypt
- **Frontend**: React, Tailwind CSS, React Router, Vite as the development environment
- **Deployment**: Managed on a cloud platform that supports Node.js applications

## Usage

### Installation

To install the necessary dependencies, follow these steps:

1. Navigate to the backend directory:
   ```bash
   cd book-reader-backend
   ```
2. Install the backend dependencies:
   ```bash
   npm install
   ```

3. Navigate to the frontend directory:
   ```bash
   cd ../react_template
   ```
4. Install the frontend dependencies:
   ```bash
   npm install
   ```

### Running the Application

- **Backend**: Start the backend server:
  ```bash
  npm run dev
  ```

- **Frontend**: Start the frontend development server:
  ```bash
  npm run dev
  ```

Make sure to have both servers running to test the full functionality of the application. You can manage your Google Translate API key within the application settings interface and utilize the integrated translation features directly in the book reader.
