# Project Summary
The English Book Reader project is a web-based application designed to enhance English reading and learning experiences through a diverse collection of books. The platform targets both casual readers and language learners, offering features like real-time translation, text-to-speech capabilities, and personal book management. By integrating tools that support reading comprehension and vocabulary enhancement, the application aims to create an engaging and immersive reading environment. It utilizes a user-friendly interface and supports multilingual access through the Google Translate API.

# Project Module Description

### 1. User Authentication
- **Login and Registration**: Secure account creation and login using email/password or OAuth (Google and GitHub).
- **User Profile Management**: Update profile information, including display name and preferred language.

### 2. Book Management
- **Book Upload**: Admins can upload books in various formats (EPUB, PDF, TXT).
- **Book Listing**: Users can view categorized books with search and filter options.
- **Bookshelf Functionality**: Manage personal bookshelves by adding or removing books.

### 3. Reading Features
- **Book Reader**: Read books with word and sentence translations.
- **Text-to-Speech Integration**: Audio pronunciation for words and phrases.
- **Reading Progress Tracking**: Save and track reading progress across sessions.

### 4. Personal Bookshelf
- Organize and manage saved books, mark favorites, and track reading progress.

### 5. Responsive Design
- Fully functional on various devices for a seamless reading experience.

### 6. API Key Management
- Manage Google Translate API key through an integrated UI.

# File Description Inventory

- **Backend Files:**
  - `src/index.js`: Initializes the Express application and configures middleware.
  - `src/routes/*`: Defines API routes for authentication and book management.
  - `src/controllers/*`: Contains business logic for handling requests and responses.
  - `src/models/*`: Defines data models for users and books.
  - `src/utils/fileParser.js`: Utility functions for parsing book files.

- **Frontend Files:**
  - `src/App.jsx`: Main component for routing and layout.
  - `src/components/*`: Manages books, user profiles, authentication, and other features.
  - `src/utils/api.js`: Functions for interacting with the backend API.
  - `src/config/apiConfig.js`: Configuration and management of the Google Translate API key.

# Technology Stack

- **Backend**: Node.js, Express, MongoDB (or appropriate storage mechanism), JWT, bcrypt
- **Frontend**: React, Tailwind CSS, React Router, Vite
- **Deployment**: Managed on a cloud platform supporting Node.js applications

# Usage

### Installation

To install the necessary dependencies, follow these steps:

1. Navigate to the backend directory:
   ```bash
   cd book-reader-backend
   ```
2. Install the backend dependencies:
   ```bash
   npm install
   ```

3. Navigate to the frontend directory:
   ```bash
   cd ../react_template
   ```
4. Install the frontend dependencies:
   ```bash
   npm install
   ```

### Running the Application

- **Backend**: Start the backend server:
  ```bash
  npm run dev
  ```

- **Frontend**: Start the frontend development server:
  ```bash
  npm run dev
  ```

Ensure both servers are running to test the application's full functionality. Manage your Google Translate API key within the application settings interface to utilize integrated translation features directly in the book reader.
